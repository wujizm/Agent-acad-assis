模型与搜集设置

首次使用请在本机终端运行 codex login 完成官方登录。这里不需要填写 API Key。模型名称需是该账户可用的 Codex 模型。

在项目 .env 中填写 LLM_BASE_URL、LLM_MODEL、LLM_API_KEY 后重启。兼容 Chat Completions；切换接入方式会保留这些配置。

资料保存在本机。使用 Codex 时，选中的资料文本会发送至 OpenAI，额度与计费取决于 CLI 的登录方式；使用 API 时发送至所配置服务。测试连接也会发起一次简短模型请求。

可选搜集服务

首次配置可复制 .env.example 为 .env，勿覆盖已有配置；修改后重启。

OPENALEX_API_KEY（可选）
增加论文元数据、摘要和作者单位来源。
BRAVE_SEARCH_API_KEY（可选）
在主题指定的可信域名中搜索其他资料。

接入方式保存后立即生效，重启后保留；运行任务期间无法切换。未配置模型也可搜集、编辑、导出和检索原文。
