# 材料学资料整理 Agent：第一版实施计划

## 目标与范围

个人本地网页应用，以主题组织论文、书籍、机构报告、可信网页和用户上传的资料。数据库是唯一结构化数据源，Excel、单篇 Markdown、综述与方向总结都是可重新生成的输出。第一版使用 Python + SQLite + 原生 HTML/CSS/JavaScript，不引入多 Agent、向量数据库或云端部署。

## 字段与约定

- “主体”按“主题”处理。
- 资料名称保留原题名；另存中文题名、英文题名；期刊/出版社/发布机构单独保存。
- 每条资料记录：稳定 ID、类型、原题名、中英文题名、来源、作者、作者单位及其来源、一句话简介、年份、DOI/ISBN、网址、获取日期、内容覆盖范围、原始摘要/正文、来源说明、人工核验状态。
- 作者单位只用来源明确提供的关联信息，不把出版社作为作者单位。缺失字段明确显示“未提供”；机译题名标注为机器翻译。
- 同一主题内按 DOI、书籍标识、规范化 URL、题名+年份去重。不同主题分别收录；书籍不同版本不应仅按书名合并。
- “原始资料”包括可获得的原始元数据、提取文本及用户上传的文件；不承诺自动获得付费论文或整本书。
- 每条资料都有独立 Markdown 文件、原始记录 JSON，上传文件保留原件。界面中的修改才是权威修改，生成文件不用于反向同步。

## 开发流程与验收

1. **数据底座**：主题、资料、证据片段、来源记录、稳定 ID 与去重。
   - 验收：重复导入不增加重复记录；补充正文不丢失已有元数据；跨主题查询互不混淆。
2. **搜集与导入**：Crossref 搜集论文及其他带 DOI 的资料；Open Library 搜集书籍；可选 OpenAlex 补充摘要/作者单位；可选 Brave 按指定可信域名搜集网页。支持 URL、手工文本、PDF/TXT/Markdown 上传。
   - 验收：各来源失败独立显示，不能把连接失败显示成“未找到”；摘要和全文严格区分；扫描 PDF 无文本时要求 OCR。
3. **资料目录**：Excel 自动筛选、冻结标题、可读列宽、网址和单篇文件链接；生成每条资料的 Markdown 卡片和整个主题 ZIP。
   - 验收：Excel 行数与数据库一致，ZIP 中的相对链接能找到对应文件；特殊字符不能成为公式。
4. **阅读与写作**：可配置的 Chat Completions 兼容模型接口；翻译题名、整理单篇要点；生成约 1500–2500 字综述及约 800–1200 字方向总结。
   - 验收：仅使用已获取的证据；引用必须落到真实资料/片段；仅有题名不能支持研究结论；内容截断、覆盖数量、生成时间与资料版本可见。
5. **知识库问答**：原始文本分块，中英文关键词检索，配置模型后可扩展查询并生成带引用回答；未配置模型时仍可搜索原文。
   - 验收：回答只引用检索到的片段；没有证据时明确不足；不把生成综述再次当作原始证据。
6. **界面与回归检查**：主题管理、搜集、导入、编辑、阅读、导出、报告、问答；长任务有进度和错误提示。
   - 验收：自动化测试覆盖去重、来源转换、检索、引用约束、报告失效标记、Excel/ZIP、HTTP 边界；本地浏览器完成实际操作检查。

## 计划检查结果

五项需求都有明确输入、持久化数据和输出；无循环依赖。先实现整条可运行链路，再扩展检索源或语义索引。当前不需要用户提供具体材料方向即可完成通用底座。

需保留的边界：未配置模型时不伪造 AI 综述；没有全文时不声称通读；来源域名仅代表采集范围，不代表结论已被核实；本地存储不等于本地推理，用户主动运行 AI 功能时会把相关文本发送至其配置的模型服务。
